## 项目简介

Hello Flow 是一款面向软件研发团队的项目管理工具，支持需求管理、任务流转、缺陷跟踪、迭代管理，提供看板视图和统计报表。

本项目为 **Web 端**，提供交互页面。服务端项目请访问 [hello-flow-server](https://github.com/dkbnull/hello-flow-server)。

## 功能特性

### 工作台

一页纵览全局，快速掌握工作状态：

- **统计卡片**：待处理任务、待我审查、待测试、我的缺陷，点击直达对应列表
- **我的任务**：最近更新的分配给我的任务，显示任务 ID、标题、状态、所属项目
- **通知动态**：实时消息流，跟踪项目内操作动态
- **项目进度**：参与项目的完成率概览，进度条可视化

### 项目管理

以项目为核心组织研发工作：

- **项目列表**：卡片式展示，显示名称、状态、任务进度、项目经理、成员数、当前 Sprint
- **项目概览**：统计卡片 + 当前 Sprint 进度 + 任务状态分布图 + 最近活动
- **模块管理**：维护项目内功能模块（名称/排序），用于任务的模块归属分类
- **版本管理**：管理项目发布版本（版本号/状态/发布日期），版本状态包括未发布、已发布、已归档，版本与缺陷解决时的修复版本关联
- **项目设置**：编辑基本信息、指定项目经理/开发主责/测试主责、归档项目
- **成员管理**：添加/移除成员，主责角色不可直接移除
- **标签管理**：项目级标签（创建/编辑/删除）

### 任务管理

覆盖任务全生命周期的流转与跟踪：

- **多类型任务**：需求、完善、缺陷三种类型，自动生成任务编码（如 `HELLO-0001`）
- **状态流转**：未开始 → 进行中 → 待审查 → 待测试 → 已完成 → 已关闭，支持取消和重新打开
- **审查机制**：开发工程师审查（PM不能审查；项目中仅自己一个开发工程师时可审查自己），审查不通过打回开发工程师
- **缺陷跟踪**：测试阶段提交缺陷自动创建子任务，指派开发工程师；缺陷类型任务支持完整解决流程（解决状态/缺陷原因/解决方案/修复版本）
- **延期标记**：标记延期任务并记录原因
- **多维筛选**：按状态、类型、优先级、处理人、Sprint、关键词筛选，支持快捷筛选（分配给我/待我审查/我创建的/已延期）
- **保存筛选**：将常用筛选条件保存为快捷视图，下次一键加载
- **自定义列**：任务列表支持列显隐配置与排序，按个人偏好展示，配置持久化到后端
- **任务关联**：支持父子任务和关联任务（关联/依赖/重复）
- **任务详情**：独立全页面（非侧滑面板），左右两栏布局，集成描述（Markdown 格式）、缺陷解决信息、附件上传与预览、父/子任务、关联任务、评论（Markdown）、操作历史时间线
- **我的任务**：独立入口汇总分配给我的任务，支持 URL query 快速筛选

### 看板视图

按状态分列展示任务，直观掌控项目进度：

- 按状态分列展示任务卡片，列头显示状态名称和数量
- 顶部 Sprint 筛选（含"全部"选项），切换查看不同迭代的看板（含子任务）
- 点击卡片跳转任务详情页进行状态流转操作
- 卡片按优先级从高到低排序

### 迭代管理

Sprint 驱动的迭代交付：

- **Sprint 列表**：表格展示，显示名称、状态、时间范围、目标，支持创建/编辑/开始/完成
- **Sprint 详情**：独立页面展示迭代基本信息 + 内嵌迭代看板
- **状态管理**：计划中 → 进行中 → 已完成，统一状态流转
- **燃尽图**：理想线 vs 实际线，跟踪迭代进度

### 通知中心

实时感知项目动态，不错过关键信息：

- **消息类型**：任务分配、状态变更、重新打开、评论、系统通知，以彩色 Tag 标签展示
- **已读筛选**：按全部/未读/已读筛选通知列表
- **未读标记**：蓝色圆点 + 高亮背景标识未读消息，支持"全部标记已读"
- **顶栏提醒**：铃铛 Badge 显示未读数量
- **通知设置**：邮箱通知总开关

### 用户与权限

基于 RBAC + 职位的精细化权限控制：

- **系统角色**：管理员（系统管理）、普通用户（参与项目）
- **全局职位**：项目经理（PM）、开发工程师（DEV）、测试工程师（QA），一人一职
- **项目主责**：每个项目设开发主责和测试主责，待测试任务自动指派测试主责
- **路由守卫**：未登录跳转登录页，非管理员禁止访问管理后台

### 管理后台

管理员专属的系统管理功能：

- **用户管理**：创建/编辑/启用/禁用用户，分配角色和职位（不支持删除用户和重置密码）
- **项目管理**：全局项目管理，创建/编辑项目（归档在项目设置中操作）
- **字典管理**：左右双栏布局管理字典类型和字典数据（不支持删除）

### 个人设置

- **个人信息**：修改昵称、邮箱、手机号，用户名/职位/角色只读
- **通知偏好**：邮箱通知总开关

## 用户角色与权限

### 系统角色（RBAC）

| 角色 | 编码 | 说明 |
|------|------|------|
| 管理员 | ADMIN | 系统级管理，不参与项目内任务流转 |
| 普通用户 | USER | 参与项目的用户，权限由职位决定 |

### 职位

| 职位 | 编码 | 职责 |
|------|------|------|
| 项目经理 | PM | 统筹项目、管理需求、分配任务 |
| 开发工程师 | DEV | 执行开发任务、提交审查、可担任开发主责 |
| 测试工程师 | QA | 测试任务、提交缺陷、可担任测试主责 |

## 快速开始

### 环境要求

- Node.js 18+
- npm 9+

### 安装

```bash
npm install
```

### 运行

```bash
npm run dev
```

启动后访问 `http://localhost:5173`，开发服务器自动将 `/api` 请求代理至 `http://localhost:8080`。

### 构建

```bash
npm run build
```

### 预览构建产物

```bash
npm run preview
```

## 开发说明

### API 代理

开发环境下，Vite 将 `/api` 前缀的请求代理至后端服务 `http://localhost:8080`，配置见 [vite.config.js](vite.config.js)。

### 路由守卫

- 未登录用户访问需认证页面 → 跳转登录页（携带 redirect 参数）
- 已登录用户访问登录页 → 跳转工作台
- 非管理员访问管理后台 → 跳转 403 页面
- 已登录但用户信息缺失 → 自动加载当前用户信息

### Token 刷新机制

- 请求拦截器自动注入 `Authorization: Bearer <token>`
- Token 过期（401）时自动刷新，刷新期间并发请求排队等待
- 刷新失败强制登出并跳转登录页
- blob 响应类型跳过业务码校验（用于附件预览/下载）
